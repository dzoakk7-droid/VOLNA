# Волна — демо музыкального приложения

Это готовый мобильный веб-плеер (PWA) с интерфейсом на русском языке:
- персональная «Волна» и подборки;
- раздел «Ремиксы» с фильтрами;
- поиск по демо-каталогу;
- избранное, перемешивание, повтор, перемотка;
- установка на главный экран телефона после размещения на HTTPS-хостинге;
- оболочка кешируется для повторного открытия, но аудио требует интернет.

## Как запустить прямо сейчас
1. Распакуйте архив на компьютере.
2. Для локального просмотра запустите в папке `python -m http.server 8000`.
3. Откройте `http://localhost:8000` в браузере. Для установки на телефон нужен HTTPS-хостинг.

## Установка на телефон
Разместите все файлы в одном каталоге HTTPS-хостинга (например, GitHub Pages или Netlify), откройте ссылку на телефоне:
- Android/Chrome: меню браузера → «Установить приложение» / «Добавить на главный экран».
- iPhone/Safari: «Поделиться» → «На экран Домой».

## Музыка
Встроены демонстрационные MP3-адреса SoundHelix. Это не каталог Spotify/SoundCloud и не личная рекомендация на основе истории прослушивания. Доступность потоков зависит от сети и стороннего хостинга. Чтобы выпустить полноценный коммерческий сервис, нужны легальный музыкальный каталог/лицензии, сервер и аккаунты пользователей.
