# Волна Beta 7

## Что нового
- Цветовая тема сайта и нижних панелей приведена к мягкой лавандово-фиолетовой палитре.
- Название «волна» в шапке сделано наклонным курсивом.
- Главный экран разделён на подборки: стартовая волна, популярное сейчас, спокойный вайб, электроника и фонк, ремиксы и новые версии.
- Добавлен выбор стартового жанра: Поп, Hip-hop, Электроника, Фонк, Рок, House, Chill или Ремиксы.
- Выбранный жанр сохраняется на этом устройстве и используется при следующем запуске.
- Кнопка запуска волны включает первый трек из выбранного жанра.
- Сохранены разворачиваемый плеер, перемотка, избранное, поиск и рекомендации похожих песен.

## Установка на Android
Это PWA, не APK. Распакуй архив и размести все файлы на HTTPS-хостинге. Открой адрес в Chrome на Android → меню ⋮ → «Установить приложение» / «Добавить на главный экран».

## Ограничения
Поиск и потоковое воспроизведение требуют интернет. Каталог Audius содержит независимые релизы и пользовательские загрузки; это не полный каталог коммерческих хитов. Подборки загружаются из Audius и могут быть недоступны, если API временно не работает. Перед повторным распространением записей проверяй права и условия сервиса.
