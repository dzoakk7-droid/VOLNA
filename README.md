# Волна Beta 9

Сборка из присланного HTML-кода с добавленными необходимыми файлами PWA (manifest, service worker и иконки-заглушки).

## Запуск
- Для быстрого просмотра откройте `index.html` в браузере.
- Для установки как PWA нужен HTTPS-хостинг или локальный сервер; затем откройте сайт в Chrome на Android и выберите «Установить приложение»/«Добавить на главный экран».

## Примечания
- В исходном интерфейсе использованы внешние изображения Picsum, Font Awesome CDN и демонстрационные MP3 SoundHelix; для них нужен интернет.
- Это ZIP с исходниками сайта, не APK.
