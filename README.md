# Волна Beta 8

PWA-музыкальный плеер без обязательной регистрации.

## Что нового
- Главная страница переработана по предоставленным примерам: плитки быстрых плейлистов, горизонтальные карточки миксов и рекомендованные станции.
- Нижний мини-плеер с перемешиванием; кнопка перемешивания подсвечивается, когда режим активен.
- Полноэкранный плеер с большой обложкой, перемоткой, переходом на 15 секунд, предыдущим/следующим треком, повтором и перемешиванием.
- Каталог ищет русские и англоязычные запросы через Audius. Рекомендации учитывают последний выбранный/избранный трек, его жанр и исполнителя, а также историю прослушивания на этом устройстве.
- Избранное и история прослушивания хранятся локально в браузере.

## Установка
Разместите содержимое архива на HTTPS-хостинге, затем откройте адрес в Chrome на Android и выберите меню ⋮ → Установить приложение / Добавить на главный экран.

## Ограничения
Это PWA, не APK. Каталог Audius состоит из доступных на сервисе загрузок независимых авторов и не гарантирует наличие всех коммерческих песен или ремиксов. Рекомендации являются лёгкой локальной системой ранжирования, не профессиональной моделью персонализации. Для поиска и потокового аудио нужен интернет.
