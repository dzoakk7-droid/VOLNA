# Волна Beta — Android/PWA

## Что добавлено
- Тёмный мобильный интерфейс на русском языке.
- Демо-треки для проверки воспроизведения.
- Онлайн-поиск аудио в Internet Archive с фильтром по метаданным лицензии Creative Commons.
- Проверка файлов в элементе metadata и воспроизведение MP3/OGG/WAV, если доступно.
- Раздел ремиксов/DJ-сетов, избранное, повтор, перемешивание, перемотка.
- PWA-манифест с PNG-иконками 192/512 и Service Worker.

## Установка на Android
Это PWA, а не APK. Для установки нужно разместить ВСЕ файлы архива на HTTPS-хостинге. После этого откройте URL сайта в Chrome на Android → меню ⋮ → «Установить приложение» или «Добавить на главный экран» → «Установить».

## Музыкальный каталог и права
Встроенные SoundHelix MP3 — демонстрационные тестовые записи, не популярные песни.
Онлайн-поиск использует публичные API Internet Archive и пытается показывать аудиозаписи, у которых в метаданных указан URL Creative Commons. Метаданные не являются юридической гарантией прав; перед повторной публикацией или коммерческим использованием лицензию конкретной записи необходимо проверить на странице источника. Популярные коммерческие треки и ремиксы на защищённые композиции нельзя легально раздавать через собственный сервис без разрешений правообладателей. Наличие песни в поиске не означает разрешение на её использование.
Каталог зависит от доступности API, корректности метаданных, CORS и качества исходных файлов. Поиск/потоковое аудио требуют интернета.

## Локальный тест
В папке с файлами выполните `python -m http.server 8000`, затем откройте `http://localhost:8000`. Service Worker и установка PWA требуют HTTPS (или localhost).
