# Волна Beta 3

## Изменения
- Интерфейс ближе к привычным музыкальным сервисам: нижняя навигация, мини-плеер над ней, быстрые подборки, компактные строки треков и обложки.
- Кнопка ♡ у каждой песни добавляет/удаляет её из избранного. Избранное сохраняется локально.
- Предыдущий/следующий трек, перемешивание, повтор и перемотка.
- Источник каталога заменён: вместо Internet Archive используется открытый API Audius для популярных треков и поиска ремиксов/жанров.
- Демо MP3 остаются резервом, если API временно недоступен.

## Установка на Android
Это PWA, не APK. Распакуй архив и размести все файлы на HTTPS-хостинге. Открой адрес в Chrome на Android → меню ⋮ → «Установить приложение» / «Добавить на главный экран».

## Ограничения
Audius содержит независимые релизы и пользовательские загрузки; это не полный каталог коммерческих хитов. Наличие трека не означает разрешение на повторное распространение или коммерческое использование. Перед публикацией нужно соблюдать условия сервиса и проверять права на записи. Поиск и потоковое воспроизведение требуют интернет; API и потоки могут временно быть недоступны.
